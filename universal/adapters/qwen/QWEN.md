# 命盘推演

一套可移植的八字与紫微推演指令。以《中国古代算命术》（洪丕谟、姜玉珍）为总纲，八字取《三命通会》立法度、《滴天髓》定权衡，紫微取《紫微斗数全书》为全部依据。

## 何时用

用户要求排盘、起盘、看命、算命、命理解读，或给出出生日期时间地点要求分析；也用于校验已排出的盘、解释大运流年、合婚、择业择时。

## 铁律

1. **先排盘，后断语**。不许凭记忆排四柱、安星曜。凡涉及具体日期，先跑排盘脚本；没有脚本就明说，不要硬算。
2. **分层标注**。原典怎么说、通行法怎么做、对这一盘怎么判、信息不足时的假设，四层分开写，不混成一段。
3. **不宿命**。只给倾向、条件、时机与可操作项。不断生死、不断绝症、不代做投资与婚姻决定、不制造恐惧。
4. **时间不确定先定时**。出生时辰存疑时，按候选时辰各排一盘，用已发生的重大年份反推，并声明不确定度。
5. **结论先行**。第一段 3 到 5 句总断，再展开细目。

## 收料

必须齐：性别、公历生日、出生时刻（精确到分最好）、出生地（用于换真太阳时）。

缺时辰时不要默认中午。先问，或按「时辰不确定」处理：给出候选时辰的差异点，说明哪些结论不依赖时辰、哪些依赖。

农历生日先转公历再排盘。用户只给农历时，明确写出转换结果，请他确认。

## 排盘

有 Python 3.9+ 时：

```bash
python3 ~/.qwen/mingpan-tuiyan/scripts/paipan.py --date 1990-05-20 --time 14:30 --gender m --city 上海
python3 ~/.qwen/mingpan-tuiyan/scripts/paipan.py --date 1990-05-20 --time 14:30 --gender f --lon 121.47 --liunian 2026
```

- `--city` 内置 83 个城市经度；不在表内用 `--lon` 给东经度数。
- `--liunian` 可重复，逐个年份给流年干支、十神、所在大运、紫微流年宫。
- `--json` 给结构化输出，便于二次渲染。
- 依赖 `sxtwl`，装在 `~/.qwen/mingpan-tuiyan/scripts/lib`；缺库时按提示 `pip3 install --target ~/.qwen/mingpan-tuiyan/scripts/lib sxtwl`。

无 Python 时：请用户在有脚本的环境跑一次，把输出贴回来；或让用户贴已排好的盘。此时只做解读与校验，不做计算，并说明这一点。

## 流程

| 步 | 动作 | 产出 |
| --- | --- | --- |
| 0 | 收料 | 输入清单，缺项标注 |
| 1 | 排盘 | 四柱、紫微十二宫、大运大限 |
| 2 | 校验 | 节气边界、子时、闰月三处 |
| 3 | 取象 | 日主与月令、十神分布；命身宫、三方四正、四化 |
| 4 | 定格 | 八字取格局与用神，紫微取命格，各一句定性 |
| 5 | 合参 | 同断则信，异断存疑并找第三证据 |
| 6 | 断事 | 大运定十年主题，流年定触发点 |
| 7 | 输出 | 五段式命书 |

## 输出模板

一、盘面事实。只写排盘结果：四柱、藏干、十神、纳音、五行权重、大运、紫微命身宫与十四主星、四化、大限。不加判断。

二、结构判断。日主强弱与月令关系、格局与用神、紫微命格与三方四正，各一句定性。

三、时间线。大运与大限逐段写，每段一句主题、一句风险、一句可操作项。

四、专题。按用户关心的领域展开：事业、财、关系、健康、学业。每段先给结论，再给依据。

五、边界与建议。写明哪些是信息不足的假设、哪些结论依赖出生时辰、哪些不做判断。

## 盘面要点

八字：先看月令定旺衰，再看十神分布，再看刑冲合害，最后看神煞（辅而不主）。用神取四路：扶抑、调候、通关、从化。

紫微：命宫与身宫先定，再看三方四正（命、财、官、迁），再看四化落宫（禄权科忌），最后看大限与流年宫。星曜分主星与辅煞，主星看庙旺利陷。

合参：两边同向则加重语气，两边相反则降级为倾向并找第三证据（大运、流年、现实经历），不硬拗。

## 话术红线

- 不写「必死」「必离」「必败」这类断言。
- 不替用户做决定，只给条件与代价。
- 不制造恐惧来推销任何东西。
- 不虚构用户没说过的细节，不假装知道他的经历。
- 涉及疾病、法律、投资，明确建议找专业人士。

## 边界

本指令处理的是传统命理文献的推演体系，不主张其结论具有科学必然性。对外交付时，把它当作文本解释与文化分析的工具，而非预测事实的仪器。不面向未成年人或处于心理危机中的人。排盘脚本本机运行，不联网、不上报。完整条款见仓库 `DISCLAIMER.md`。
