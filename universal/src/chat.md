# 纯对话环境怎么用

适用于豆包、千问网页版、ChatGPT、Claude、Gemini 这类只有对话框、不能执行代码的产品。

## 三条路

**一、贴盘。** 你自己或别人已排好四柱与紫微，把盘面贴进来，让模型解读。这是最稳的用法。

**二、借脚本。** 找一台有 Python 的机器（或让本机的 agent）跑一次：

```bash
python3 scripts/paipan.py --date 1990-05-20 --time 14:30 --gender m --city 上海 --json
```

把输出贴回对话框。结构化 JSON 比纯文本更好用，模型不容易读错位。

**三、粗排。** 你没有盘、也没有脚本，但想先看看。告诉模型「未校验，粗排」，它按传统口诀推，结果只当讨论用，不做决策依据。

## 贴盘模板

复制下面这段，把盘面填进去：

```text
请按命盘推演的方法解读。
性别：男
公历生日：1990-05-20 14:30
出生地：上海（真太阳时 14:39）
四柱：庚午 辛巳 乙酉 癸未
大运：壬午 5.6 起，顺行，每十年一换
紫微：命宫戌，身宫子，土五局，紫微在亥，天府在巳
四化：太阴化科、天同化忌（财帛），武曲化权（子女），太阳化禄（夫妻）
想了解：近三年事业与现金流，以及要不要换赛道。
```

缺项就写「未知」，不要留空让模型猜。

## 三个常见坑

1. **模型自己排盘。** 它很容易把节气、闰月、子时算错，而且看起来很像对的。凡涉及具体日期，坚持让它用脚本结果。
2. **只给年份不给时刻。** 时柱错，紫微命宫就错，整盘偏。宁可先定时辰。
3. **农历当公历。** 说清楚是哪一个，转换后让它复述一遍确认。

## 让输出更好用

- 先说你要什么：事业、财、关系、健康、学业，选一两个。全都要，深度会被摊薄。
- 要求它写「依据」。没有依据的断语，多半是套话。
- 要求它写「不确定的部分」。肯说不知道的，比句句笃定的可信。

## 边界

这是传统文化文本的解释与推演，不构成医疗、法律、投资、婚姻建议。命理结论请当参考，不做重大决策的唯一依据。
