# 30 实战

排盘是算术，推演是判断，交付是沟通。这一节讲后两件。

## 一、收料

起盘前必须齐的五项，缺一项就在输出里标注。

| 项 | 为什么必须 | 缺了怎么办 |
| --- | --- | --- |
| 性别 | 定大运顺逆、紫微大限方向 | 无解，必问 |
| 公历生日 | 排四柱 | 只给农历则先换算，并注明换算依据 |
| 出生时刻 | 定时柱与命宫 | 缺则按 12 时辰各排，走定时程序 |
| 出生地 | 定经度，矫正真太阳时 | 缺则用省会，并注明误差 |
| 关注议题 | 定输出的重点 | 缺则给通盘，不逐宫铺陈 |

另问三项可提高精度：是否闰月生、是否为双胞胎、是否有明确记得的大事件年份。

## 二、定时

出生时辰不确定时，不要猜，做排除。

1. 按候选时辰各排一盘（通常 2 到 4 个）。
2. 取当事人记得的三到五个大事件年份（升学、迁徙、婚育、重病、破产、升迁）。
3. 逐盘对照：该年在八字大运流年上是否见明显冲合，在紫微上是否见大限流年四化落于对应宫。
4. 取吻合度最高的一盘，把不吻合处作为存疑点写出来。

判断口径：**一两个事件吻合是巧合，三个以上同向才可作为定时依据**。若两盘各有胜负，就明确告诉用户「此时辰无法确定，以下按 A 盘推，B 盘的可能性另注」。

## 三、输出模板

五段，顺序不改。

**一、盘面**：只写排盘事实。公历、真太阳时、四柱、大运起运、紫微命身宫与五行局。不加形容词。

**二、结构**：三到五句定性。八字给格局与用神，紫微给命格与身宫落点。例：「日主乙木生于巳月，食伤当令而印绶无根，属身弱用印之比。紫微命宫天机在巳，身宫落官禄，一生着力点在事业。」

**三、时间线**：按大运分段，每段一句主题，标出转折年。紫微大限并行标注。

**四、专题**：只讲用户问的，最多三个。每个专题走「结构 → 倾向 → 时间 → 表现 → 建议」五步。

**五、边界**：这一盘的信息不足处、流派分歧处、以及不属于命理能回答的问题。

篇幅：通盘 800 到 1500 字；专题 300 到 500 字。超过即是堆砌。

## 四、六大专题

| 专题 | 八字入手 | 紫微入手 | 常见误判 |
| --- | --- | --- | --- |
| 事业 | 官杀与食伤的强弱、格局成败、大运是否助格 | 官禄宫主星与四化、命宫与官禄的关系 | 把「有官星」直接等于「有职位」 |
| 财运 | 财星得地否、身能否任财、比劫是否夺财 | 财帛宫、田宅宫、禄存落宫 | 把「偏财旺」直接等于「会投资」 |
| 婚恋 | 日支与配偶星、合冲、女命官星、男命财星 | 夫妻宫主星与四化、身宫是否落夫妻 | 把「夫妻宫见煞」直接等于「婚必破」 |
| 健康 | 五行偏枯处、日主受克处 | 疾厄宫主星与煞星 | 把命理当诊断，说出具体病名 |
| 六亲 | 年月时柱与对应十神 | 父母、兄弟、子女宫 | 断言亲属生死 |
| 择时 | 流年干支与用神的关系 | 流年命宫与四化的落点 | 承诺「某日必成」 |

每个专题的结尾都要落到一个可执行的动作，否则只是描述。

## 五、话术与红线

**四条红线**：

1. **不制造恐惧**。不说「大凶」「必有血光」「活不过某岁」。改为「这一段压力集中，注意 X 与 Y」。
2. **不越界**。疾病建议就医、法律建议咨询律师、投资建议交给持牌机构。命理只谈倾向与节奏。
3. **不替人做决定**。可以说「这一年更适合稳」，不能说「你必须离婚」。
4. **不虚构细节**。不知道的就说不知道，不编造当事人经历来「验证」准确。

**三种句式**：

- 条件句：「若你在 X 方向投入，Y 年更容易见到结果。」
- 对比句：「同样走财运，A 运宜守成，B 运宜扩张，差别在有没有帮身。」
- 归因句：「现在这个局面，结构上来自 X，触发点是 Y 年。」不给「命该如此」。

**称呼与分寸**：对客户用「你」，不用「命主」；不自称「大师」；不承诺准确率；不诱导付费化解。

## 六、复盘

每次交付留一张表，日后再看。

| 字段 | 内容 |
| --- | --- |
| 起盘时间 | 交付日期 |
| 断语 | 原话摘录，不改写 |
| 指向年份 | 具体到年 |
| 结果 | 应验、部分应验、未应验、无法核验 |
| 归因 | 结构判断错、时间点错、还是信息不足 |

连续复盘二十盘，会发现自己反复错在同一类结构上（多半是旺衰判断偏软或神煞用得太重）。这比多读十本书有用。
